# 🍽️ Zomato Restaurant Analytics

## 📌 Project Overview
This project analyzes restaurant data from multiple countries using SQL, Excel, Power BI, and Tableau to identify business trends and customer preferences.

## 🛠️ Tools Used
- SQL (MySQL)
- Microsoft Excel
- Power BI
- Tableau

## 📊 Key KPIs
- Total Restaurants
- Average Rating
- Average Cost for Two
- Online Delivery %
- Table Booking %
- Country & City Analysis

## 📈 Key Insights
- Identified top-performing cities and countries.
- Compared restaurant ratings across regions.
- Analyzed pricing trends and online delivery adoption.
- Built interactive dashboards for business decision-making.

## 💡 Skills Demonstrated
- Data Cleaning
- SQL Query Writing
- Dashboard Development
- Data Visualization
- Business Analysis
